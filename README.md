# RPG Prototype

A browser RPG with turn-based, bullet-hell battles. You explore THE RUINS (the entrance and the Lantern Hall to the north), and when you fight, you steer your SOUL (a heart) around a box to dodge the enemy's attacks. Floating crystals are save points: touch one and the game picks up from there next time.

Like Deltarune, the world is 320x240 pixel art drawn at double size on a 640x480 canvas, and the UI is drawn at the full 640x480 so it's finer than the art. The UI font is VT323 and enemy speech bubbles use Nunito, both loaded from Google Fonts; offline, plain fonts stand in.

## Running it

The game uses JavaScript modules and loads its dialogue from `text/`, which browsers won't allow from `file://`, so it needs a little local server. Run:

```
python tools/serve.py
```

Then open http://localhost:8000 for the game, or http://localhost:8000/tools/ for Ruins Studio. The server only listens on your computer. (`python -m http.server 8000 --bind 127.0.0.1` from the project root also runs the game, but the Studio can't save with it.)

## Controls

| Key | Overworld | Battle |
| --- | --- | --- |
| Arrow keys / WASD | Move | Choose commands, steer your soul |
| Z / Enter | Read signs, talk | Confirm, hit strike rings |
| X | Hold to run, skip text | Back out of lists; hold to focus (slower soul) |
| Shift | Hold to run, skip text | Back out of lists; use your weapon's soul ability |
| C / Ctrl | Open the menu (EQUIP, SKILLS, status) | |
| M | Mute or unmute music and sound | Mute or unmute music and sound |
| Space | Jump | Jump, in a boss's HEAVY mode |

Each landing cracks the tile under you. Land on the same tile three times and it breaks, and you fall to your death.

## Ruins Studio (creator tools)

With `python tools/serve.py` running, open http://localhost:8000/tools/ for a set of editors that load the game's real data. Their **Save** button writes straight into the game's files (backing up the old version in `.studio-backups/` first); refresh the game to see the change.

- **Sprite Editor:** paint sprites and palettes, with previews and animation.
- **Room Editor:** paint tiles and place the start, doors, props and enemies.
- **Music Maker:** a piano roll and drum grid that plays songs through the game's synthesiser.
- **Pattern Lab:** test attack patterns with a soul you steer, and prototype new ones.
- **Enemy Maker:** fill in a form to get an enemy's data file, dialogue template and a checklist.

`tools/README.md` explains each tool.

**The game finds new content by itself.** These files are generated by the server from what's in their folders, so a new enemy, room, song, attack pattern or text file works as soon as it's saved:

- `src/data/enemies/index.js`, `src/data/rooms/index.js`, `src/data/music/index.js`, `src/data/patterns/index.js` and `src/data/textManifest.js`

Don't edit those by hand. If you add a file outside the Studio, run `python tools/serve.py --generate` (or just start the server) to rebuild them.

## Writing dialogue

NPCs with a face in `src/data/art/portraits.js` (keyed by their NPC id, like `old_keeper`) show it beside their dialogue, Undertale style, blinking now and then.

Everything that's said in the game lives in plain text files in `text/`, so you can write without touching code:

```
text/
  README.txt              How the format works
  enemies/                One file per enemy: intro, flavour, taunts, TALK replies, endings
  interactions/           One file per area: signs and things you can inspect
  npcs/                   One file per NPC: what they say first, and after that
  items/                  Item and weapon descriptions
  shops/                  What each shopkeeper says, including TALK topics
  skills/                 Skill descriptions
```

See `text/README.txt` for the format. New files are picked up automatically when the server (re)starts or the Studio saves.

## Battling

Walk into an enemy to start a battle. The Old Keeper in the west room has advice.

| Enemy | Where | Attacks |
| --- | --- | --- |
| Rogue Dummy | Entrance, east room | Cotton rain, sweeping rows, spirals and more (the gentlest) |
| Dust Bunny | Entrance, east room (lower) | Dust puffs that hop up in arcs |
| Lantern Moth | Lantern Hall | Weaving dust and rings of embers |
| Waxling | Lantern Hall | Wax drips that fall faster and faster |
| Shade | Lantern Hall | A ring of shadow that closes in, with a gap to escape through |

**Group battles:** enemies close to the one you touch (within about 4 tiles) join the fight, up to 3 at once. To keep it fair, at most two attack in a turn, each with fewer bullets, and the second starts a second later. With several enemies, FIGHT, TALK and the targeted spells first ask which enemy, Deltarune style, showing each one's HP and MERCY. Beaten or pacified enemies leave mid-fight, and you win when they're all gone. Your party stands on the left, the enemy on the right, against an animated backdrop of the Ruins.

On your turn, pick a command:

- **FIGHT**: three rings shrink onto a target around the enemy. Press Z as each one meets it; PERFECT hits do bonus damage.
- **TALK**: talk to an enemy. Most options raise its MERCY meter.
- **SPELLS**: spend SP (spell power) on magic.
  - Heal Pulse (32%) heals 35 HP.
  - Rend (40%) is a guaranteed 30 damage.
  - Pacify (16%) sends an enemy away peacefully, but only once its MERCY is full. The SPELLS button flashes when one is ready.
- **ITEMS**: eat Trail Mix to heal 40 HP.
- **DEFEND**: halves damage for the next enemy turn and builds SP.
- **RUN**: try to escape. It gets more likely the longer the fight goes on. The enemy stays in the room, but ignores you for a moment.

On the enemy's turn, a box opens in the middle of the screen and you steer your **soul** to dodge:

- Each turn, the enemy picks a random attack, never the same one twice in a row. Each attack also randomises its own details, such as wind direction, spin direction, where gaps open, and how its emitters move.
- Only the very centre of the soul can be hit.
- Standing still is never safe: if your soul barely moves for about a second, aimed shots fly at it until it moves (except while channelling with the Oak Staff).
- **Grazing**, like Deltarune: letting bullets pass close by lights up a larger outline around your soul and fills **SP** (the purple gauge on the left). Each new bullet you graze gives a burst of SP and shortens the enemy's turn slightly; staying close keeps SP trickling in.

Each enemy has a `difficulty` in its data file: `density` scales how often bullets spawn and `speed` how fast they fly. The rogue dummy, the first enemy you meet, uses gentle settings; the lantern moth is a step up, with its own attacks: dust that weaves across the box and rings of embers.

Beaten and pacified enemies stay gone, even after you leave the room and come back.

### Levels and skills

Winning a fight earns EXP (pacifying earns gold but no EXP, like Deltarune). The EXP needed grows every level: 20, 40, 70, 110, 160 and so on. Each level gives +8 max HP and 1 skill point, and you start with 3 points to try the tree.

Press C and choose SKILLS to spend points. The tree is drawn as three constellations in a drifting night sky, with its own slow song; learned stars glow and light up the line to the next. Each skill needs the one above it:

| VALOR | SPIRIT | RESOLVE |
| --- | --- | --- |
| Sharpened (1): FIGHT +15% | Focus (1): grazing +25% SP | Tough (1): +15 max HP |
| Keen Eye (1): wider strike window | Lull (1): spell, +30% MERCY | Steady Soul (1): longer invincibility after a hit |
| Rend (2): spell, 30 damage | Wide Graze (2): bigger graze area | Guard Up (1): DEFEND heals 8 HP |
| Flurry (2): a fourth FIGHT ring | Starfall (2): spell, 45 damage | Last Stand (2): survive one knockout per battle |

Heal Pulse and Pacify are known from the start. Skills are defined in `src/data/skills.js` (the comment there lists every effect), with descriptions in `text/skills/skills.txt`. Spell costs are in `src/data/spells.js`.

### Shops

Talking to Moss opens the shop screen, laid out like Deltarune's: Moss behind the counter in a little shop room, with a menu box (BUY, TALK, EXIT) and a dialogue box below. BUY lists every weapon with its price and details; TALK has topics to chat about. Everything Moss says, including the TALK topics, is in `text/shops/ruins_shop.txt`; any section named `talk: ...` becomes a topic.

### Weapons and soul abilities

You start with the Worn Sword and the Old Shield. Moss, the mushroom-capped merchant in the west room, runs the **RUINS SHOP**, which sells every weapon for 0 gold for now. Winning or pacifying an enemy earns gold.

Press C in the overworld and choose EQUIP. Each weapon changes how much damage FIGHT does, and most give your soul an ability you use with **Shift** while dodging. The ability is ready again at the start of every enemy turn, and a bar under the box shows when it has recharged.

| Weapon | FIGHT | Shift ability |
| --- | --- | --- |
| Worn Sword | x1 | None |
| Old Shield | x0.7 | **Block**: a barrier destroys bullets for 0.6s. 3s recharge. |
| Duelist's Blade | x0.9 | **Parry**: a quick slash around the soul. 2s recharge, or 0.6s if you parry a bullet just before it hits (which also gives SP). |
| Ash Spear | x0.85 | **Lunge**: dash the way you're moving, unhittable mid-dash. 1.8s recharge. |
| Hunting Bow | x0.6 | **Shoot**: fire arrows upward that break a bullet each. 3 per turn. |
| Oak Staff | x0.5 | **Channel** (hold): stand still; grazing builds SP 3x as fast. |
| Stone Hammer | x1 | **Quake**: clear the bullets closest to you. 7s recharge. |
| Spare Lantern | x0.5 | **Light**: a pool of light where bullets slow to a crawl for 3s. |
| Glass Dagger | x0.8 | **Phase**: blink to the opposite side of the box. 3s recharge. |
| Iron Gauntlets | x0.8 | **Reflect**: punch a nearby bullet back at the enemy for damage. |
| Chapel Bell | x0.4 | **Toll**: freeze every bullet for 0.4s. 8s recharge. |
| Old Tome | x0.5 | **Recall**: spend 20% SP to heal 12 HP mid-attack. |

Bullets destroyed by an ability give a little SP.

New weapons go in `src/data/weapons.js`, with descriptions in `text/items/weapons.txt`. New abilities go in `src/battle/soulAbilities.js`, which explains every hook an ability can use. Shops are in `src/data/shops.js`, with the shopkeeper's lines in `text/shops/`. What the hero owns, has equipped and how much gold they have is in `src/characters/heroState.js`.

### Music

Original songs are synthesised live, chiptune style, with the Web Audio API, so there are no audio files. They're written in the spirit of Toby Fox's music, with their own melodies:

- **Lantern Dark** (`src/data/music/ruinsTheme.js`) plays in the Ruins: mysterious, D minor with a dark E-flat chord, a twinkling music box over a low drone, and a sparse echoing melody.
- **Starlight Study** (`src/data/music/skillsTheme.js`) plays in the SKILLS menu: slow and dreamy, E major, soft chords and a gentle music box.
- **Old Halls Waltz** (`src/data/music/waltzTheme.js`) isn't used yet, saved for a brighter area: a waltz in 3/4, F major, with an "oom-pah-pah" accompaniment. Play it with `music: 'waltz'`.
- **Dust and Lanterns** (`src/data/music/shopTheme.js`) plays in the RUINS SHOP: slow and wistful, A minor, an echoing lead over soft chords. It's inspired by "Ruins".
- **Cotton Clash** (`src/data/music/battleTheme.js`) plays in battle: 160 BPM, E minor lifting to a hopeful second half, a brassy lead over a syncopated bass, off-beat stabs and a busy kit. It leans into the style of "Rude Buster" and "From Now On".

Menus, battles, saving and doors also have little synthesised sound effects (`SFX` in `src/audio/music.js`).

Music starts on your first key press, because browsers block sound until then. A room picks its song with `music`, a shop plays its own `music` while it's open, and an enemy can override the battle song with its own `music`. Songs are written as note text; `src/audio/notation.js` explains the format.

### Soul modes (bosses only)

Special boss battles can change how your soul works. The mode shows as the soul's colour and is explained the first time it appears:

- **HEAVY** (purple): your soul falls to the floor of the box. Press Up or Space to jump, and hold it to jump higher. Used by the `pillars` attack.

New modes go in `src/battle/soulModes.js`. An attack asks for a mode with `mode: '...'` in `src/battle/bullets.js`. Only an enemy with `boss: true` may use those attacks; any other enemy that lists one stops the battle with an error, so modes stay special.

## Rooms, doors and saving

Rooms are listed in `src/data/rooms/index.js`, each with an `id`. A room's `doors` are tile areas that lead to another room by id, with a `spawn` tile where you arrive; doorways (`D` tiles) fade to black and back. Props with `save: true` are save points: they store the hero, which enemies are beaten, and where you stood, in the browser's localStorage (`src/state/saveGame.js`). The game continues from the last save when it starts and after a game over.

To start over, clear the save from your browser's developer tools (Application, Local Storage) or run `localStorage.clear()` in the console.

## Layout

```
index.html                Page with the game canvas
css/                      Page styles
text/                     All dialogue (see above)
assets/                   Real art, audio and fonts (empty for now)
  sprites/  audio/  fonts/
src/
  main.js                 Entry point: loads fonts and text, continues from the last save
  state/                  Saving and loading, and what's remembered about the world
  config.js               Resolution (320x240) and tile size (16px)
  audio/                  Music synthesiser and the note notation songs are written in
  engine/                 Shared core: game loop, input, screen scaling and UI space,
                          sprites, text-file loading
  characters/             The hero: sprites and animation, what they carry (heroState),
                          and levels and skills (progress)
  overworld/              Exploring: scene, rooms, tileset, camera, player, props, enemies
  shop/                   The shop screen
  battle/                 Battles: scene, HUD, soul and soul modes, projectiles,
                          strike rings, area backdrops
    attacks/              Each enemy's own attacks and bullet art, one file per enemy
  gameOver/               Game over screen
  ui/                     Shared UI: text, the overworld textbox, and the C menu (EQUIP, SKILLS)
  data/                   Content, kept separate from code
    rooms/                Room layouts as text maps, with props, doors and enemies
    art/                  Placeholder pixel art and command icons as text grids
    enemies/              Enemy stats, TALK options and attack weights
    skills.js, spells.js  The skill tree and spell costs
    music/                The songs, as note data
    textManifest.js       The list of files in text/ to load (generated)
```

Each game mode gets its own folder under `src/`. Code shared between modes lives in `engine/`, `characters/` and `ui/`.

To add a room, copy `src/data/rooms/startRoom.js` and edit the map. Each tile character is defined in `src/overworld/tileset.js`. To add an enemy, copy `src/data/enemies/dummy.js` and `text/enemies/rogue_dummy.txt`, then add it to the room's `npcs` list. To add a battle background for a new area, add a function to `src/battle/backdrops.js` and set the room's `area`.
